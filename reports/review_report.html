### Finding 2
**Issue:** Possible SQL injection via string concatenation  
**Severity:** Critical  
**Category:** Security  
**Line:** 12  
**Explanation:** The function builds an SQL statement by concatenating the `user_id` directly into the query string. If `user_id` contains malicious input, an attacker can manipulate the query and compromise the database.  
**Suggested Fix:** Use parameterised queries (or an ORM) instead of string building. Example with `sqlite3`:

```python
import sqlite3

def get_user_data(conn: sqlite3.Connection, user_id: str):
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM users WHERE id = ?", (user_id,))
    return cursor.fetchall()
```

Return the fetched data rather than the raw query string.
